# TaskFlow 📝

TaskFlow is a simple and user-friendly **To-Do web application** built with **Flask and SQLAlchemy**. Users can register, log in, and manage their personal tasks.

## 🚀 Features

* User Registration & Login
* Secure Password Hashing
* Add & Manage Tasks
* Update Task Status
* Clear Tasks
* User-specific Tasks
* SQLite Database

## 🛠️ Tech Stack

* Python
* Flask
* Flask-SQLAlchemy
* SQLAlchemy
* SQLite
* HTML5
* CSS3
* Jinja2
* Werkzeug

## ▶️ Run Locally

```bash
git clone https://github.com/your-username/TaskFlow.git
cd TaskFlow
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Open `http://127.0.0.1:5000/` in your browser.
